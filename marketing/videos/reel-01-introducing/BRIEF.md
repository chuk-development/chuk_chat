## Decisions (autonomous run, recorded)

- One monolithic composition (`index.html`) generated by `tools/build.py`
  (scenes in `tools/scenes_a.py`, `scenes_b.py`, `scenes_c.py`, kit in
  `tools/common.py`). Reason: elements carry across scenes (the "Chuk Chat"
  word moves from the Introducing card into the kinetic line; the tile moves
  from the last list into the end card), and fonts are inlined only once.
  Lint therefore warns about file size and nested timeline elements; those
  warnings are structural, not defects.
- Animation: one paused GSAP timeline drives a small deterministic engine;
  every value is a pure function of time (seek-safe). Kinetic word positions
  are measured offline with the real Inter font (PIL + raqm) so the line
  re-centres as words arrive and icon slots open, as in the reference.
- Kinetic line icons: the concept lists padlock, speech and laptop. The line
  is set as the reference sets it (brand mark in line 1): "Chuk Chat [tile] is
  / your [padlock] private / AI [speech] chat". The laptop is in the burst.
- The tile is the app mark: ink rounded square with the cream logo (the app
  icon is a dark disc). "Chuk Chat" is coral in the Introducing card and the
  kinetic line; the end card uses the mono wordmark like the website.
- Chat scenes: light floating bubbles on warm paper (Inter 50 px), coral user
  bubble, paper-tile assistant bubble, avatar with a white name pill and a
  live status line (34 px). Result cards copy the real app (dark surface,
  Ubuntu + Chuk Chat Mono, markup and CSS from chuk.chat `uc/business.html`,
  `a-art`, `a-mail`, `usecases.css`), zoom 2.1, so card text is >= 33 px.
- Copy for the invoice, PDF, email, pharmacy and plan comes from the website
  worlds (`chuk.chat/content/_index.md`: business, connectors, onthego). The
  plan rows use the concept wording.
- Timing moved slightly against the concept table to cut on the music: list 1
  21-25, invoice 25-37, list 2 37-41, Android 41-49, connect 49-53, end card
  from 56.3. Content is unchanged.
- "keeps your chats encrypted" is 1040 px at 88 px, so the last list sets its
  middle phrase on two lines (88 px) instead of shrinking the type.
- "Connect your apps" is a two-line 112 px headline, not a small chip, so it
  meets the 88 px minimum.
- Android phone: the one phone frame (allowed by the concept). Phone from
  video 06 (`tools/frames_c.py` PHONE_CSS), places rows after video 01 and
  the website `uc/onthego.html`. Pushed in to 1.08 so the overlay text is
  >= 35 px, and kept inside the 120 px safe margins.
- Readability checked on full-resolution frames from the rendered MP4
  (`_work/check/`, one per beat). Headlines 112 px (lists 88-112 px), bubbles
  50 px, card text >= 33 px, status 34 px, phone overlay >= 35 px.
- No SFX (the owner adds a trending IG sound on the no-music version).

## Assets and licences

- `assets/emoji/*.png` — Microsoft Fluent Emoji, 3D style, MIT licence,
  https://github.com/microsoft/fluentui-emoji (licence text:
  `assets/emoji/LICENSE-fluentui-emoji.txt`). Only the 33 files used are kept;
  `tools/get_emoji.sh` downloads them again.
- `assets/logos/svg/*.svg` — Simple Icons (CC0-1.0,
  https://github.com/simple-icons/simple-icons, v13) for Notion, Linear,
  GitHub, Todoist, Dropbox, Figma. Used as vector glyphs so the connector
  circles stay sharp (the website PNGs are only 64 px). These are third-party
  trademarks shown as "works with" connectors, the same as on chuk.chat.
- `assets/fonts/Inter-subset.woff2` — Inter variable (OFL), subset to Latin-1
  + the signs used, axes opsz + wght kept. Source: video 05
  `InterVariable.ttf`. `OFL-Inter.txt`.
- `assets/fonts/Ubuntu-subset.woff2` — Ubuntu variable (Ubuntu Font Licence
  1.0), subset the same way. The website's app UI font.
- `assets/fonts/ChukChatMono-wght.woff2` — JetBrains Mono (OFL),
  `OFL-JetBrainsMono.txt`.
- The render inlines each font; subset woff2 keeps the page small (lesson
  from video 06).
- `assets/bgm/track.wav` — `marketing/_shared/music/05-announce-yourself.wav`
  (MP3 data) transcoded to PCM. `assets/bgm/track_edit.wav` — straight cut
  source 7.069-66.769 s (`tools/make_music_edit.sh`), 0.08 s fade-in, 0.5 s
  fade-out at the natural end. Volume 0.9. -15 LUFS integrated.
- `_work/InterVariable.ttf`, `_work/Ubuntu-wdth-wght.ttf` — measurement only
  (not loaded by the page).
