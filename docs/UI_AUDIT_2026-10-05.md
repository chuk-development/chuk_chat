# UI audit, 2026-10-05 (Agents build and Chat half)

Scope: the Agents build (`FEATURE_AGENTS`) and the plain Chat half, phone
(360 x 800) and desktop (1280 x 800). Dark and light, English and German,
text scale 1.0 and 1.3.

Method: a throwaway widget test pumps the real screens with fake data and
writes PNGs: `_scratch/ui-audit/audit_shots_test.dart`. It uses the same
approach as `test_screenshots/` (real app fonts, `RepaintBoundary.toImage`).
The shell is the real `MessengerShell` with a `FakeRelayController`. The
theme is `buildAppTheme` with the app defaults (`kDefaultAccentColor`
`#A8C7FA`, `kDefaultBgColor`, `kDefaultIconFgColor`).

Run it again:

```bash
flutter test _scratch/ui-audit/audit_shots_test.dart            # all
flutter test _scratch/ui-audit/audit_shots_test.dart --plain-name round2
```

The test "fails" after each case because of `MissingPluginException`
(record plugin) and the Supabase guard. The PNGs are written first, so the
failures do not matter.

Shots: `_scratch/ui-audit/shots/` (62 PNGs). Prefix `p` = phone, `d` =
desktop, `r2_` = second round.

Contrast numbers are measured on the PNG pixels (WCAG ratio).

## Test artifacts (not app bugs)

* White boxes in some titles (`FloatingAppBar`, snackbar, "Show 1
  finished", the settings Retry button): that text does not inherit the
  theme text style, so the test engine draws its placeholder font. On a
  device the platform font shows. See issue S-3 for the small real side of
  this.
* `p06_tab_settings.png` is empty: `SettingsPage` needs
  `SupabaseService.initialize()` (listed in `_cannotMount` of
  `test/layout/every_screen_layout_test.dart`).
* `d20*_settings_modal*.png`: the content pane shows the Supabase guard
  error. The error text itself is a real issue (S-2).
* The phone thread in round 1 shows only the last turn. The fake replay sent
  two batches. `r2_phone_thread_full.png` has the full transcript.
* The plain Chat half "chat with messages" cannot mount without Supabase.
  The Agents thread draws the same `ChukChatUIMobile` / `ChukChatUIDesktop`,
  bubbles and composer, so its shots stand in for it.

## Root cause behind many findings

**R-1 (high). `onPrimary` is the icon colour, not a colour that contrasts
with the accent.** `lib/constants.dart:209` sets `onPrimary: iconFg`. In
dark mode the default accent `#A8C7FA` and the default icon colour
`#E2E2E9` are both light: text on an accent fill measures **1.33 : 1**
(WCAG AA needs 4.5). Every selected pill segment, the selected nav capsule
icon, every filled `ExpressiveButton` and the filled toggles use it.
Seen in: `p01_inbox_dark.png` (Agents, All), `p06_tab_media.png` (nav
capsule, Pictures), `p04_thread_takeover_dark.png` (Open browser),
`p17*_telegram*.png` (Turn on, Link), `r2_p12b_coworker_model_page_scrolled.png`
(Low), `d0*_*_dark.png` (Agents). Light mode is fine (dark text).
Fix: pick `onPrimary` by contrast against `accent` (dark navy or white,
whichever is above 4.5 : 1). Keep `iconFg` only when it passes.

**R-2 (high). User bubble text in dark mode is 2.0 : 1.**
`lib/widgets/message_bubble/layout.dart:251` fills the bubble with
`accent @ 0.8` and the text stays `iconFg`. Measured `#E2E2E9` on
`#8AA3CD`. Both halves draw this bubble. Seen in `p02_thread_dark.png`,
`d02_thread_dark.png`, `r2_p15b_room_chat.png`. Fix: text colour from the
same contrast rule as R-1 (it becomes dark on the default accent).

**R-3 (medium). The pastel accent is used as a foreground in light mode.**
Selected roster name `1.33 : 1` (`d03_thread_live_takeover_light.png`),
roster icons "New", "Control Rooms", "Search" `1.43 : 1`, agent-accent
times in the inbox `1.75 : 1` (`p01_inbox_light.png`), the check icon of
the "continues" card (`p18c_takeover_continuing_light.png`). Fix: in light
mode, derive a darker foreground variant of the accent for text and icons
(for example `Color.lerp(accent, black, 0.55)`, the value that
`onPrimaryContainer` already uses at `lib/constants.dart:171-173`).

## Agents inbox (phone)

Shots: `p01_inbox_dark.png`, `p01_inbox_light.png`,
`p01_inbox_dark_x1.3_de.png`.

Verdict: the structure matches the Grok Bot model (floating top row, plain
list, nav pill). Contrast (R-1), tinted rows and the name truncation make it

1. **high** Selected "Agents" / "All" and the nav capsule icon are
   unreadable in dark mode. Fix: R-1.
2. **med** The coworker name is cut to "Amber Fi…" (1.0) and "Amb…" (1.3)

   name must not be ellipsised. Fix: wrap `_RoleTag` in `Flexible` with a

   `lib/services/agents/agent_roster_source.dart:260-268` names the host

   host's hostname from the status frame), a subtitle, and the same row

5. **low** Rooms come first, above the coworkers. The Grok Bot list is
   bots first. Fix: coworkers first, rooms in their own group under them,

6. **low** Room faces overlap so the first letter is half hidden ("A" under
   "C"). Fix: smaller second face with a ring, or the `+N` chip the Control
   Rooms list uses.
7. **low** The room subtitle is a list of handles

   different room subtitles (inbox: handles, Control Rooms: "5 members",
   desktop roster: handles). Fix: one rule, ideally the last line said.
8. **low** DESIGN §4 says four destinations (Chats, Media, Files,
   Settings). The pill has three. Update the doc (see D-1).
